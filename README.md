# Mini Amazon Clone

A responsive front-end e-commerce demo built with HTML, CSS and vanilla JavaScript.

## Run it
1. Extract the ZIP file.
2. Open `index.html` in Chrome, Edge, Firefox or another modern browser.
3. Browse products, search/filter, add items to cart, save wishlist items and try the demo checkout.

## Features
- Amazon-inspired navigation and shopping layout
- Product cards, search and category filtering
- Product detail popup
- Add/remove products and adjust quantities
- Wishlist hearts
- Cart subtotal and item count
- LocalStorage persistence for cart and wishlist
- Responsive mobile layout
- Demo checkout confirmation

No installation or build step is required. Product visuals use emoji illustrations and the page uses Google Fonts when internet access is available.
